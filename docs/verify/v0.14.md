# v0.14 — manual verification

Windows image clips in Clipboard History. Plan:
[`../plans/v0.14-clipboard-kinds.md`](../plans/v0.14-clipboard-kinds.md).

**Nothing here has been run.** This script covers the Windows half only. The
macOS watcher, image capture and paste-back remain open under v0.12 row 6 and
v0.14. Record the date, Takyon build, Windows version and status of each step.

Run [`../../scripts/verify-guard.ps1`](../../scripts/verify-guard.ps1) first.
[`../../scripts/verify-drive-v0.14.ps1`](../../scripts/verify-drive-v0.14.ps1)
drives the automatable part against a release build in a sandboxed data
directory: image capture into a sealed blob, the History view, Ctrl+D
and Ctrl+K deletion shredding the blob, and Copy restoring the pixels. Run it
with `powershell -STA`. It does not replace the steps below that need a person.
Build with `bun run build`, never bare `cargo build --release`. Use a disposable
Takyon profile: the retention and Clear history steps permanently remove clips.
Keep the `clips\` directory open at
`%LOCALAPPDATA%\v3sper\takyon\clips\`. Its `.bin` names are random 32-hex
identifiers, not row ids. Record filenames before and after deletion rather than
assuming an id maps to a filename. Prepare four distinguishable image clips on
the previous day: three for section C and one for retention in section D. If
they are unavailable, prepare them and resume those sections tomorrow. Keep
retention longer than one day until section D.

## A. Capture and preview

| # | Step | Expected | Status |
|---|---|---|---|
| A1 | Press `Win+Shift+S`, select a region with visible detail, then open Clipboard History | One Image clip appears with a thumbnail, dimensions and PNG byte size. A new `.bin` file appears in `clips\` | |
| A2 | Open the Image clip in the full preview | Full image matches the selected region. Closing and reopening it still works | |
| A3 | In a browser, right-click an image and choose **Copy image**, then open History | Image appears with a thumbnail. This tests the registered `PNG` or DIB path from a browser | |
| A4 | Copy selected cells in Excel, or Word text with formatting, then open History | One Text clip records the selected text, not the bitmap offered alongside it | |
| A5 | Copy an image in a browser that offers both text and image formats, if available | Text wins. Record the browser and source; this is the known limitation in `docs/tbd/v0.14.md` §4 | |

## B. Paste-back

| # | Step | Expected | Status |
|---|---|---|---|
| B1 | Select the screenshot clip in History, paste it into Paint | Paint receives the full image at its original dimensions, not the 256 px thumbnail | |
| B2 | Select the browser image clip, paste it into Word | Word receives the image. Text is not pasted instead | |
| B3 | Copy another text clip, then paste the saved screenshot again | Paste-back restores the selected image to the clipboard before sending `Ctrl+V` | |

## C. Selective deletion

Use three distinct image clips from yesterday, while retention still keeps
them. After each action, compare `clips\` filenames with the previous snapshot.

| # | Step | Expected | Status |
|---|---|---|---|
| C1 | Select the first old image in History and click **Delete** in its detail pane | Only that clip disappears. Its `.bin` file disappears; neighbouring clip becomes selected | |
| C2 | Select the second old image and press `Ctrl+D` | Only that clip and its `.bin` file disappear | |
| C3 | Select the third old image, press `Ctrl+K`, and choose Delete | Action menu works inside History. Only that clip and its `.bin` file disappear | |

## D. Retention, clear and size

| # | Step | Expected | Status |
|---|---|---|---|
| D1 | Open Settings → Clipboard after several image captures | On-disk history size is a number and increases after another image capture | |
| D2 | Keep one image clip older than one day, set retention to **1 day**, and wait for the next retention sweep | Old clip and its `.bin` file disappear. A newer clip remains | |
| D3 | Click **Clear history** in Settings → Clipboard | History is empty and `clips\` contains no `.bin` files | |

## E. Exclusions and restart reconciliation

After Clear history, capture two new test images. Use one for E2's orphan copy
and the other for E3's missing-file row.

| # | Step | Expected | Status |
|---|---|---|---|
| E1 | Copy a password from a password manager that sets `ExcludeClipboardContentFromMonitorProcessing` | No clip appears and no blob file is created | |
| E2 | With Takyon stopped, put a copy of an existing encrypted `.bin` blob under a new 32-hex filename in `clips\` without adding a database row. Restart Takyon | Startup reconciliation removes the orphan file; History remains usable | |
| E3 | With Takyon stopped, remove a test image clip's `.bin` file. Restart Takyon | Startup reconciliation removes the row whose blob is missing; other clips remain | |

For E2 and E3, use test clips in the disposable profile only. Restore nothing
from another profile: its encryption key will differ. E3 intentionally destroys
the selected test clip.
