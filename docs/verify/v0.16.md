# v0.16 — manual verification

Focus sessions: apps quit, websites sent to the block page and brought back,
Snooze, Pause, Strict, and the hurdles. Run against an installed release build,
never `bun run dev`: the shutdown hurdle, startup resume and the floating bar's
focus behaviour only exist on a real window.

The block page is written per session to
`%LOCALAPPDATA%\v3sper\takyon\focus\blocked.html`, themed with the live family.
`Alt+Space` belongs to Raycast here, so summon with the rebound hotkey.

**Written before the phase is built.** Steps name the behaviour the plan
specifies. Correct them against the build, not the other way round.

## What automation already covers

Do not redo these by hand:

- Duration parsing, host matching, identity matching, the session clock with
  pauses and sleep, snooze expiry, Strict friction, `categories.json`'s schema,
  and `protected.rs` refusing Takyon: `cargo test --lib focus`.
- `focus.db` round trip, resume at startup, and quitting a test-spawned process
  that honours `WM_CLOSE` and one that ignores it: `cargo test --test focus`.
- Reading and navigating each installed browser's address bar:
  `cargo test --test focus -- --ignored --nocapture`.
- Every Focus surface in every theme half: `bun run test:visual`.

## A. Apps

1. Open Discord and Notepad. Start a Soft session, goal `verify`, 10 minutes,
   Block list: Discord. Discord closes within 2 s; Notepad does not.
2. Launch Discord again. It closes before its window can be used.
3. Minimise Discord to the tray before starting a fresh session. It still closes
   within 2 s, through the poll rather than the foreground hook.
4. Add an app run as administrator (any `Run as administrator` tool) to a Block
   list. The start form lists it as "Can't block <app>: runs as administrator"
   before the session starts.
5. Put Takyon in a Block list. It is refused with a message, not filtered
   silently.
6. Block a Steam game through the Games Focus category. Launching it from Steam
   gets it quit; Steam itself is quit too.
7. Turn Restore Terminated Apps on, block Discord, complete the session. Discord
   reopens once.

## B. Websites

Once with Chrome, once with Firefox, and once with Edge if installed.

1. Open `youtube.com` and `m.youtube.com` in two tabs. Start a Soft session
   blocking `youtube.com`. The active tab goes to `Blocked · Takyon` within a
   second; the background tab is untouched until you switch to it, then it goes
   too.
2. Open `notyoutube.com` (or any domain ending in the blocked one without a dot
   boundary). It is not blocked.
3. Complete the session early. Both block-page tabs return to their exact
   original URLs, with the path intact.
4. Start a session ending in 2 minutes, block a site, and close Takyon from the
   tray before it ends. When the end time passes, the block page's own timer
   returns the tab.
5. Use a private window. Blocking works the same.
6. Block a site while the only open browser is unsupported (any Chromium fork not
   on the list). The start form says "Can't block sites in <browser>".
7. Confirm the block page made no request: browser devtools' Network tab on
   `blocked.html` shows nothing but the file itself.
8. The block page shows the goal as its heading, the blocked host, and a
   countdown to the session's end, in the active theme family. Switch the family
   and appearance in Settings, start a new session, block again: the page
   follows.

## C. Snooze, Pause, Complete

1. Soft session blocking Discord, snooze 3 min. Open Discord, then Snooze from
   the bar's block line. Discord stays usable while in front. After 3 minutes,
   switch away; it closes then, not while you are typing in it.
2. Pause for 5 minutes. Everything is usable and the bar's clock stops. At the
   end, the bar nudges and blocking resumes with the time left unchanged.
3. Edit the running session: add 10 minutes and youtube.com. Both take effect
   without restarting it.
4. Set Snooze duration to No Snooze. The block line offers no Snooze.

## D. Strict

1. Start a Strict session. The block line never offers Snooze.
2. Pause asks for the goal to be retyped, then counts down 30 s. Dismissing the
   Palette mid-countdown resets it.
3. Quit from the tray asks to confirm.
4. Kill `takyon.exe` in Task Manager. Relaunch. The session resumes with the
   correct time left and blocking restarts.
5. Reboot mid-session. After login, autostart brings Takyon back and the session
   resumes, with the time before the reboot counted.
6. Start → Shut down. Windows shows "Takyon is preventing shutdown" with
   "Focus: <goal>, <n> min left". Cancel returns to the desktop with the session
   running. Repeat with Shut down anyway and confirm it shuts down.
7. Leave the machine idle past its sleep timeout. It does not sleep. End the
   session; it now does.
8. Turn both hurdles off in Settings and repeat 6 and 7. Neither holds.
9. Sleep from the Start menu mid-session. It sleeps. On wake the session is
   still running with the time left as it was when the machine slept.

## E. The floating bar

1. While typing in another app, start a session from `!f verify 5m` (switch `!f`
   on first). The bar appears and the app you were typing in keeps focus.
2. Drag the bar, end the session, start another. It reappears where it was left.
3. Hover shows Pause and Complete. Clicking them does not steal focus from the
   app underneath for longer than the click.
4. Collapse to the tray. A block flashes the tray icon, and its tooltip shows the
   countdown and the block line.
5. Measure RSS with the bar showing: the whole Takyon tree in Task Manager's
   Details view. Record the number in `docs/tbd/v0.16.md`.

## F. Settings and stats

1. Duplicate the Social Focus category, edit the copy, and start a session with
   it. The built-in is unchanged.
2. Export a custom Focus category, delete it, import the file. It comes back.
   Import it again; the second copy gets a suffix.
3. Focus stats over 7 days shows the sessions from this script, split by Focus
   category, with the most-blocked list led by Discord.
4. Scheduled sessions and Locked appear as Coming soon text, with no control to
   click.
5. Clear Focus history. Focus stats is empty.

## G. Network

Run the whole of A to F with a firewall rule blocking `takyon.exe` outbound, or
watch it in Resource Monitor's Network tab. Focus makes no request at any point.
