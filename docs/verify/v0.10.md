# v0.10 verification — Appearance

Run against a **release build** (`bun run build`, then the installed binary), not
`bun run dev`. Two of these sections cannot be reached any other way: the window
modes resize a native window, and the Windows-key hook needs a real desktop.

Unlike a plan, this script never goes stale. Re-run it on any regression, and run
it with every other script in this directory at v1.0.

Record each step as **pass / fail / blocked**, with the reason for anything that
is not a pass.

---

## A. Themes

The set is five families × two halves. A1 is the one that matters most: light
mode shipped from v0.6 to v0.9 with an invisible panel border and an invisible
selection, and this is the step that would have caught it.

- **A1.** Settings → Appearance. Turn **Follow system appearance** off, choose
  **Light**. Open the Palette and type something. Check, by eye and deliberately:
  - the panel has a visible **outer edge** against the desktop behind it;
  - the **selected row** is visibly filled;
  - the footer's **keycaps** (`↵`, `Ctrl K`) have a visible fill and border;
  - the hairline under the input row is visible but not heavy.
- **A2.** Repeat A1 over a **light wallpaper** and then a **white full-screen
  window**. The panel edge has to survive both; that is what `--color-edge` is
  for and it is the case a dark desktop hides.
- **A3.** Walk all five **Light theme** families. For each: the window repaints
  immediately, no control loses contrast, and no text becomes unreadable.
- **A4.** The same five as **Dark theme**, with the appearance pinned to Dark.
- **A5.** With Halide selected in both halves, type `!s something`. The outbound
  row and the answer header must read as **warmer and more urgent** than the
  accent — this is the one family where accent, warning and outbound are all in
  the warm half (ADR-0023).
- **A6.** Set **Follow system appearance** on. With the Palette open, flip
  Windows between light and dark (Settings → Personalisation → Colours). The live
  half changes within a second. **Neither stored choice changes** — go back to
  Settings → Appearance and confirm both pickers still show what you chose.
- **A7.** Choose a **Dark theme** while Windows is in light mode. It must be
  selectable and must not repaint the window. The badge reads *on screen now* on
  Light theme only.
- **A8.** Quit and restart. Both halves and the appearance mode survive.
- **A9.** Upgrade check, on a profile that ran v0.9 with an appearance override:
  the override survives (`ui.theme` → `ui.appearance`). If you have no such
  profile, set `ui.theme` to `light` by hand in `settings.db`, delete
  `ui.appearance`, and restart.

## B. Window modes

- **B1.** Compact (the default). The Palette opens **68px** tall and grows one row
  at a time as results arrive, capping at eight rows. Unchanged from v0.9.
- **B2.** Switch to Expanded in Settings. **With the Palette already open**, it
  resizes at once rather than on the next summon.
- **B3.** Expanded, empty query: the window is a fixed height and shows
  **Suggestions grouped under category headings**. It does not resize as you type.
- **B4.** Expanded, empty query: the **mark is holding still**. If it is
  breathing, the idle beat is lying about state — the shell is idle, but a full
  list says otherwise.
- **B5.** Expanded, type until there are more Entries than fit. The **list
  scrolls inside the window**; the window does not grow.
- **B6.** Expanded, then `!c` with a question and Enter. The Chat Surface is
  `VIEW_HEIGHT` (560), **not** `EXPANDED_HEIGHT` (520) — a View outranks the mode.
  Escape returns to an Expanded root.
- **B7.** Expanded, `Ctrl+K` on a row. The action menu fits and is not clipped.
- **B8.** Expanded at each Interface size (Small, Default, Large). The window
  height scales and the list still fills it, with no gap above the footer.
- **B9.** Fresh profile: the first view is **empty**, because nothing has been
  launched yet. This is expected (`docs/tbd/v0.10.md` §8) — confirm it is empty
  rather than broken, then launch three things and re-open.

## C. Category grouping

- **C1.** Expanded, type a query matching an application, a file and a settings
  page. Groups appear in the order their **best Entry** appeared — the ranking
  still decides, the grouping only labels.
- **C2.** A Kind that appears twice, either side of another Kind, draws **one**
  section rather than two.
- **C3.** Arrow keys walk every Entry in order and **skip the headings**.
- **C4.** Compact, the same query: **no headings**, one flat list.

## D. Keyboard

- **D1.** The chord is a **dropdown**, not chips. Arrow keys, Home, End and
  typeahead all work in it; Escape closes the list without dismissing anything
  behind it.
- **D2.** Rebind to `Ctrl+Space`. The old binding releases, the new one works,
  and it survives a restart.
- **D3.** Rebind to something already held (`Alt+Space` with PowerToys Run
  running). The error appears beside the control and the **previous binding stays
  live** — check by pressing it.
- **D4.** Reset returns to `Alt+Space` and is disabled when already there.

## E. The Windows key — **not yet run by anyone**

The whole of ADR-0024's mechanism is reasoned rather than observed. This section
is `docs/tbd/v0.10.md` §3 and it blocks the phase's exit.

- **E1.** Settings → Keyboard. The switch is **off** on a fresh profile.
- **E2.** Turn it on. **Tap** the Windows key: the Palette opens and **the Start
  menu does not**. Tap again: the Palette hides.
- **E3.** Hold Windows and press `R`. The **Run dialog** opens and the Palette
  does not.
- **E4.** The same for `Win+E` (Explorer), `Win+D` (desktop), `Win+Tab` (task
  view) and `Win+.` (emoji). All unaffected.
- **E5.** `Win+L`. The machine **locks**. Log back in and confirm the hook is
  still armed.
- **E6.** Hold Windows for three seconds and release without pressing anything.
  Auto-repeat must not queue a stream of injected keys, and the Palette should
  open once on release — or not at all, but not twice.
- **E7.** Turn the switch off. Tap Windows: **Start opens on the first tap**, not
  the second. A second tap that is needed means a stuck modifier.
- **E8.** With the switch on, quit and restart Takyon. Tap Windows: it still
  works. The hook is re-armed rather than reporting success against nothing.
- **E9.** Type continuously in another application for a minute with the hook
  armed. No dropped or doubled keystrokes, and no perceptible latency.
- **E10.** Open an **elevated** window (Task Manager, or an admin terminal) and
  give it focus. Tap Windows. **Expected to fail** until the UIAccess certificate
  lands (`docs/tbd/v0.10.md` §4) — record which it did, because that is the datum
  that decides whether the switch's description is honest.

## F. File Search

- **F1.** Settings → File Search. The scopes list names each root on its own row,
  and the entry count is beside the heading.
- **F2.** Add a scope by typing a path. The row appears and the count starts
  moving. Remove it: the row goes and the count returns.
- **F3.** Remove every scope. The empty state names the **consequence** — that
  `!e` will find nothing — rather than just saying the list is empty.
- **F4.** Add an ignore pattern. The row appears; the count drops.
- **F5.** **Reset to defaults**, with a custom root added first. The confirmation
  names the real counts. After confirming, the roots return to what Takyon probes
  for this machine, both switches turn off, and the index rebuilds.
- **F6.** After F5, restart. The reset stuck — the stored rows were removed rather
  than overwritten, so a machine that gains a code directory later picks it up.
- **F7.** The **Remove** button on each row is reachable by `Tab`, not only by
  hovering.

## G. Regressions this phase could have caused

- **G1.** `bun run bench`, all four budgets, in **Compact**. Nothing here should
  have moved them; the theme is seven custom properties written once per mount.
- **G2.** Re-run `docs/verify/v0.6.md` in full. Every settings control moved or
  was re-tokenised, and Appearance is a new page in the middle of tier one.
- **G3.** Re-run `docs/verify/v0.9.md` §7b. The outbound header changed from a
  Tailwind constant to a theme role, which is exactly the surface that section
  exists to watch.
- **G4.** The tray icon still swaps polarity when the **system** theme changes.
  It keys off Windows, not off Takyon's appearance override, and that is
  deliberate — the tray sits in Windows' notification area, not in our window.
