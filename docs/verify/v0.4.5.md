# v0.4.5 manual verification

The calculator card. One task, so one short script.

Run [`../../scripts/verify-guard.ps1`](../../scripts/verify-guard.ps1) first, and
build with `bun run build` rather than bare `cargo build --release`.

`Alt+Space` is held by Raycast on the development machine, so these assume the
`TAKYON_HOTKEY` override — `Ctrl+Alt+Shift+F9` is what the drivers use.

---

| # | Step | Expected | Status |
|---|---|---|---|
| H1 | Type `12*1.18` | A **card**, not a row: `12*1.18` on the left, `→`, **14.16** on the right, `Expression` and `Result` labelled beneath, `Calculator` captioned above | pending |

| H5 | Type `40 kg to lb` | `88.1849 lb` as the Result, `40 kg to lb` as the Expression | pending |

## J — Window height, which is the part that can actually break

The card is not `ROW_HEIGHT` tall, so Rust's window arithmetic had to learn about
it. **Playwright cannot catch a mistake here** — it renders in a browser with no
native window, so a card that overflows looks perfect in a screenshot and clips
in the product.

| # | Step | Expected | Status |
|---|---|---|---|
| J1 | Type `12*1.18` | The window ends just under the card. No empty shadowed strip below it, and no scrollbar | pending |
| J2 | Type `2024` | Card **and** the application rows below it, all visible, no clipping of the last row | pending |
| J3 | Type a query returning a calculation and many apps, e.g. `2022` | The list scrolls rather than the window growing without limit. Card plus eight rows is the ceiling | pending |
| J4 | Type `code` (no calculation) | Ordinary rows, window exactly as before v0.4.5. The card must not reserve space when there is no card | pending |
| J5 | With a calculation shown, press `Ctrl+K` | The menu fits inside the window; nothing is cut off at the bottom | pending |

J4 is the regression check: `calc_card` defaults to false, and a stale `true`
left in `Shape` would make every subsequent query too tall.
