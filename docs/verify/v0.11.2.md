# v0.11.2 — manual verification

Agent fallback and a faster `!s` (ADR-0041). Run against an installed build,
never `bun run dev`.

Section A needs an Agent that has really run out of usage. Claude Code's
five-hour window is the easiest one to exhaust. Sections B and C need no
exhausted Agent.

## What automation already covers

Do not re-do these by hand:

- The bench: ordering, expiry, Claude's reset time, the seven-day cap, and the
  chain building for first and resumed Turns: `cargo test --lib agents::fallback`.
- Claude's `rejected` rate-limit frame recording its reset, and tools-off Turns
  passing `--strict-mcp-config`: `cargo test --lib agents::claude`.
- A missing Agent falling through to a fake `.cmd` Agent that answers, every
  Agent failing as `exhausted`, an Agent that wrote text and then failed *not*
  being replaced, and a chain of one keeping its own reason:
  `cargo test --test agents_cli v0_11_2`.
- `pages` returning at its deadline without the straggler, and as soon as every
  page is in: `cargo test --lib search::fetch`.
- Exa page text reaching the summariser and skipping the fetch:
  `cargo test --lib search::exa search::synth`.
- The handover drawn in the Palette: `bun run test:visual`
  (`palette-ask-fallback.png`). The reducers and the `exhausted` copy:
  `bun test turnState searchState status`.

## A. A real usage limit — **needs an exhausted Agent**

Settings → Agents order: Claude Code first, Codex second, both switched on.

1. With Claude Code out of usage, type `!c what is 2+2` and press Enter.
   - [ ] One line above the answer reads "claude couldn't answer, so codex is."
   - [ ] The header names Codex, and Codex's answer appears.
2. Escape, then type `!c what is 3+3`, but do not press Enter yet.
   - [ ] The row says "Ask Codex — press Enter · Claude Code unavailable". The
     bench moved Claude last, so no Claude process is spawned for this one.
3. Press Enter.
   - [ ] Codex answers with no fallback line. Task Manager shows no `claude`
     process starting.
4. Type a follow-up in the same view.
   - [ ] Codex answers it, resuming its own session. Claude is not asked.
5. `!s population of iceland`, press Enter.
   - [ ] The status line ends "Codex is writing…", and the fallback line sits
     under the question.
6. Switch Codex and opencode off in Settings, leaving only Claude Code, then ask
   `!c hi`.
   - [ ] The failure is Claude's own limit sentence, not "No Agent could answer".
     A chain of one keeps its own reason.
7. Switch Codex back on, but leave it signed out (`codex logout`), and ask `!c hi`.
   - [ ] "No Agent could answer. Tried Claude Code, Codex. Sign in to one with
     usage left…", with Codex's own reason on the line below.

## C. `!s` is faster

With no Exa key stored:

1. `!s who won the 2022 world cup`, Enter, and time from Enter to the first
   finding appearing.
   - [ ] "Reading 10 web pages" lasts at most about 4 seconds, even when one
     source is slow.
2. Store an Exa key, then repeat C.1 with a new question.
   - [ ] The reading phase is close to instant: no page is fetched.
   - [ ] Source favicons still appear, and they may land after the answer starts.
3. Settings → Agents shows a third picker per Agent reading "!s: haiku (fast)",
   "!s: gpt-6-luna (fast)" and "!s: opencode/big-pickle (fast)".
   - [ ] A `!s` answer from Claude Code is written by Haiku. Task Manager's command
     line for `claude.exe` shows `--model haiku --effort low`.
4. Set Claude Code's `!s` model to "!s: same as !c", with `opus` and `high` locked
   for `!c`, then repeat C.1.
   - [ ] The command line shows `--model opus --effort high`.

## E. Answers stay open on a click away (ADR-0042)

1. `!c Name every planet, one line each`, Enter, then click into another window
   while it answers.
   - [ ] The answer stays on screen and keeps streaming. The footer reads "Stays
     open when you click away · Esc to go back".
2. Press the hotkey.
   - [ ] The answer comes back to the front with the follow-up input focused. It
     is not hidden.
3. Press the hotkey again.
   - [ ] Now it hides.
4. Type `notepad` (the list, no Bang), then click away.
   - [ ] The Palette closes, as it always did.
5. Turn off Settings → Agents → "Keep answers open when you click away", then
   repeat E.1.
   - [ ] A click away closes the answer, and the Agent process is gone.
