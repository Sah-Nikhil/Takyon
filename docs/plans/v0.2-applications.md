# v0.2 Launching applications

First phase worth using daily. Lands when you stop opening the Start menu.

## Read first

v0.1 done, benchmark recorded. `IMPLEMENTATION_PLAN.md` §2, §3, §6, §8.

## Tasks, in order

1. **`Source` trait + pipeline skeleton** (§3). One `invoke` per keystroke. Fan
   out on rayon pool, 20 ms deadline. Source that misses deadline returns nothing
   for that keystroke.
2. **`sources/apps.rs`.** Four discovery paths, separate code each:
   - Start Menu `.lnk`, both `%APPDATA%` and `%PROGRAMDATA%`
   - `shell:AppsFolder` for UWP/Store apps and Settings pages
   - executables on `PATH`
   - Steam via `libraryfolders.vdf` + per-game `.acf` manifests
3. **`EntryId` stability.** Resolved target path. Never a hash of display name.
   Display names change on app update, Frecency resets silently.
4. **`rank.rs`, matching only.** No Frecency yet. Tiers from §3: alias,
   full-name prefix, first-word prefix, later-word prefix, exe basename, acronym.
5. **`icons.rs`.** Lazy extraction into one mmapped `icons.bin`, keyed by target
   path + mtime. Off the UI thread. Missing icon = placeholder, never blocks a row.
6. **`api.ts` + Palette UI.** Virtualised list, keyboard only, `seq` on every
   query so slow keystroke cannot overwrite fast one.
7. **Launch on Enter.** Palette hides immediately, not after app window paints.
8. **`Ctrl+K` action menu**, shared primitive. Every Source and Mode contributes.
   Build now, before three Sources exist. Retrofit means touching all of them.
9. **Modifier accelerators**, user rebindable, listed inside the action menu.

## Traps

**No React component calls `invoke()` directly.** All through `api.ts`. One
violation and TBC-0007's visual test layer stops covering that component.

UWP apps are not files. No path to `CreateProcess`. Launch via shell
`AppsFolder` parsing name.

Extracting hundreds of icons on the UI thread looks exactly like the product
being slow. The one thing it cannot afford.

`.lnk` files point at targets that vanish. Resolve and drop dead ones at index
time, not launch time.

## Exit criteria

Use instead of Start menu for a full day, zero fallbacks.
