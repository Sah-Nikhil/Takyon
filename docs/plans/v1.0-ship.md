# v1.0 Ship

Someone who is not you installs it and uses it for a week.

## Read first

ADR-0010 (zero telemetry), ADR-0011 (identity vs display name), TBC-0002 (the
warm-window bet, now resolvable with real numbers), `docs/brand.md`.

## Tasks, in order

1. **Installer.** NSIS. Must install to a trusted location, because UIAccess
   requires it.
2. **Code signing.** Already needed at v0.1 for UIAccess, so this is verification
   rather than new work. Confirm the uninstall hook removes the `Run` key.
3. **Updater.** `tauri-plugin-updater`, feed keyed on `com.v3sper.launcher`, not
   on the display name.
4. **First run.** Hotkey introduction, autostart prompt, index roots confirmation.
   Short. A launcher that opens with a wizard has already lost.
5. **Crash logs.** Written locally, settings button opens the folder, nothing is
   ever sent. State that plainly in the README.
6. **Full benchmark pass on a cold machine.** All four budgets plus `!e` p95.
7. **Resolve TBC-0002.** Write the real numbers in, then mark it resolved or
   triggered. If triggered, the verdict section already says what to do.
8. **Redraw the timing chart from real bench output.** The current numbers in
   `docs/brand.md` are budgets, not measurements. Publishing them as measured
   would be a lie.
9. **Licence decision.** Open source or proprietary. It has been open the whole
   project and it constrains dependencies.

## Traps

The `Run` key must not survive uninstall. Test the actual uninstaller, not the
dev path.

An MSIX identity change forces every user to reinstall and loses their data.
`com.v3sper.launcher` is fixed. Renaming the product later touches UI copy only,
which is the entire point of ADR-0011.

SmartScreen reputation accrues per signed binary. Early installs will warn.
Expect it, do not panic and re-sign under a different name.

Shipping telemetry in the same release as the privacy promise would undermine
both. Post-V1, opt-in, and its own ADR (ADR-0010).

## Exit criteria

A person who is not you installs it, uses it for a week, and does not go back to
what they used before.

## Manual verification

1. Clean Windows VM, install, reboot, hotkey works at login.
2. Palette appears over an elevated terminal (UIAccess proof).
3. Uninstall. No `Run` key, no leftover data unless the user chose to keep it.
4. Update from the previous version, confirm settings, Frecency and clipboard
   history all survive.
5. Benchmark on the VM, not the dev machine.
