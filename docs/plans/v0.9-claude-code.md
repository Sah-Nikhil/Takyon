# v0.9 Claude Code

Ask a question from the hotkey, get an answer in place.

## Status: design not finished

Deliberately parked until the base app works. Four decisions below are open. Do
not start building until they are answered, because each changes the shape of the
code.

## Read first

ADR-0001 (launcher first, lazy Promotion), `CONTEXT.md` for Promotion and Chat
Surface, `docs/plans/bang-registry.md`.

## Settled already

Takyon holds no LLM account and no API key. It drives the user's own `claude`
CLI as a subprocess. That was the original point of the feature and it does not
change.

Promotion is lazy (ADR-0001). One question answered inline never creates a Chat
Surface. A follow-up does.

## Open questions

1. **Session model.** One long-lived `claude` process per Chat Surface, or a
   fresh process per turn resumed with `--resume <session-id>`? Fresh-per-turn is
   simpler and survives crashes. Long-lived is faster per turn. Measure before
   choosing.
2. **Working directory.** Claude Code is a coding agent and its answers change
   with the repo it sits in. A launcher has no project context. Neutral scratch
   directory, last-used directory, or ask? Neutral is the safe default and may be
   wrong for the most useful cases.
3. **Missing or logged-out CLI.** Detect and explain, versus fail. Explain, but
   the wording matters and belongs in this plan when written.
4. **Tool policy.** Inline Palette answers with tools disabled, full agent mode
   only inside a promoted Chat Surface. An agent that can edit files must never
   be one keystroke from a global hotkey. This one is close to settled but should
   be confirmed explicitly.

## Shape, once decided

1. Subprocess with `--output-format stream-json`, newline-delimited events
   rendered as they arrive.
2. Inline answer in the Palette, tools off.
3. Promotion on first follow-up. Chat Surface is a separate window with its own
   lifecycle. Escape on the Palette never destroys a conversation.
4. Chat Surface carries full agent mode, if question 4 lands where expected.

## Traps

Streaming JSON means partial lines. Buffer until newline. A half-parsed event
rendered as text is the classic bug here.

`claude` startup is not free. Whatever the session model, the first token latency
on the inline path is what people will judge.

Working directory is a security question as much as a usability one. An agent
with tools, running in a directory the user did not choose, is a bad surprise.

Escape must not kill an in-flight request that a Chat Surface owns.

## Exit criteria

A question answers inline in the Palette. A follow-up promotes into a Chat
Surface. Escape on the Palette never destroys a conversation.

## Manual verification

Written when the plan is finished. It cannot be specified before the four
questions are answered.
