# v0.1 Warm shell

Empty Palette, instant. Plus benchmark that decides if ADR-0003 was right.

Phase exists to test warm-window bet, not ship features. Bad numbers → plan
changes shape now, not at v0.9.

## Read first

ADR-0003 (warm window), ADR-0011 (identity slug), `IMPLEMENTATION_PLAN.md` §7 and
§10. Also `tesseract/docs/plans/launch-at-startup.md` before any autostart code.
Tesseract solved this already.

## Tasks, in order

1. **Bun workspace.** `apps/desktop` = Tauri 2 + React 19 + Vite 7 + Tailwind v4
   (`@tailwindcss/vite`). `packages/shared` empty but present. Scripts: `dev`,
   `typecheck`, `lint` (tsc + `cargo clippy`), `test`, `bench`.
2. **Identity.** Package identity, data dir, `Run` value, mutex all use
   `com.v3sper.launcher`. Data at `%LOCALAPPDATA%\v3sper\launcher\`. "Takyon"
   appears only in UI copy and installer.
3. **`window.rs`.** One Palette window at startup, hidden. Show/hide. Never
   destroy. On hide call `SetProcessWorkingSetSize(-1, -1)`.
4. **`hotkey.rs`.** `Alt+Space` via `tauri-plugin-global-shortcut`. Registration
   failure surfaces as visible error, never silent no-op.
5. **Dismissal.** Escape hides. Focus loss hides. Always opens empty.
6. **Placement.** Monitor holding cursor.
7. **`tray.rs`.** Tray icon, Settings + Quit. Port tesseract's
   `self_heal_autostart` (refreshes `Run` entry after update moves binary).
8. **Autostart.** `tauri-plugin-autostart` + `tauri-plugin-single-instance`. On by
   default via first-run prompt. Add `autostart:default` to
   `capabilities/default.json` or frontend calls fail at runtime, not build.
9. **UIAccess helper.** Separate signed exe, `uiAccess="true"`, trusted location,
   brings Palette to foreground. Dev builds skip it, accept no-show over elevated
   windows.
10. **Deferred init.** Hotkey answers within ~50 ms of launch. Everything else
    after.
11. **`bun run bench`.** Four budgets from `IMPLEMENTATION_PLAN.md` §10. Write
    results into `docs/tbc/0002`.

## Traps

**Dev builds must never register autostart.** Gate Rust with
`#[cfg(not(debug_assertions))]`, UI switch with `import.meta.env.DEV`. A debug
registration writes a `Run` key pointing at `target\debug\` that survives
uninstalling the real app.

**Autostart state belongs to the OS.** Read via `isEnabled()` on mount. Never
mirror into settings, or the two disagree the first time someone edits the
registry.

WebView2 = several processes. Memory measurement reading only main process is
wrong.

**Bench must include first show after 30+ min idle.** Windows reclaims trimmed
working set. Tight loop never sees it. That number decides ADR-0003.

## Exit criteria

`Alt+Space` anywhere in Windows → empty Palette under 50 ms. Escape dismisses.
Four benchmark numbers in `docs/tbc/0002`, including cold first show after long
idle.

## Manual verification

1. Hotkey from maximised app, desktop, and over elevated terminal.
2. Escape hides. Click other window hides.
3. Reboot, autostart on. Hotkey answers within 500 ms of login.
4. Autostart off, reboot. No launch, no orphan `Run` key.
5. `bun run dev` → autostart switch disabled with reason, no registry write.
6. Two monitors. Opens on the one holding cursor.
