# v0.8 — what is not done

Agents landed: the `AgentDriver` trait, drivers for Claude Code, Codex and
opencode, Sign-in probes, `!c`, the inline answer, Promotion into a conversation
in the same window, the ranked Agent order with a switch per Agent, the locked
model and effort, and the Settings page. What follows is outstanding, with the
phase that owns each.

---

## 1. There is no permission UI, so tool prompts are denied — **v1.0**

Every Turn runs with permission prompts refused: `--permission-prompts none` for
Claude, `--sandbox read-only` or `workspace-write` for Codex, and opencode's
default (not `--auto`). Nothing in Takyon can answer a prompt, so a Turn that
raised one would wait forever, and denying is the only setting that cannot hang.

The consequence is real and it lands on the follow-up Turns, where tools are
supposed to be on: an Agent asked to edit a file gets as far as the permission
check and is refused. It can read, search and run what its permission mode
already allows, and no further.

Fixing it is a UI, not a flag: an approve/deny row inside the conversation, wired
to Claude's `--permission-prompt-tool` and the equivalents. That is a v1.0-sized
piece of work and it was not in this phase's exit criteria.

## 2. The `Ctrl+K` Agent switch is not built — **v1.0**

`bang-registry.md` settles that the Agent is a preference switchable for one
query from the action menu. The preference shipped as a ranked order with a
switch each; the per-query override did not. `!c` walks whatever Settings says,
and reaching a different Agent means opening Settings and moving it up.

Blocked on nothing — the action menu is built and `agent_ask` already takes the
Agent as an argument. It was cut for scope, and it is the input that tells us
whether one Bang per Agent (also in `bang-registry.md`) is the better shape.

## 3. A conversation dies with the Palette — **v1.0**

The transcript lives in React state inside the Palette, and the Palette is
dismissed by Escape and by focus loss. Click away mid-answer and the conversation
is gone from Takyon. The Agent's own session file survives on disk, so it still
exists and Takyon can no longer find it.

**This is the price of one window**, and it was paid deliberately: the alternative
was a second window, which is what v0.8 removed. Two things would fix it, and
neither is small enough for this phase. A table of
`(agent, session id, title, last used)` and a way back in — `!c` with an empty
query is the obvious door, and `bang-registry.md` lists exactly that question as
open. And suppressing dismiss-on-focus-loss while a Turn is in flight, which is a
change to `window.rs`'s focus rules rather than to anything in `agents/`.

Until then Escape goes back one step rather than dismissing, which at least means
the conversation survives the keystroke most likely to be pressed by accident.

## 4. There is no way back to a finished conversation — **v1.0**

Same root as §3 seen from the other side: nothing lists past conversations, so
"what did I ask yesterday" has no answer inside Takyon. Needs the same table.

## 5. Claude's model list is aliases, not a catalogue — **v1.0**

`codex debug models` and `opencode models` both report real model ids. `claude`
has no models command, so its picker offers the four aliases its `--model` help
documents — `opus`, `sonnet`, `haiku`, `fable`.

That is deliberately not a bundled catalogue: an alias resolves to the latest of
its family, so it cannot go stale, while a pinned list of full model names would
be wrong within a release or two. What it costs is the ability to lock to one
exact model rather than to a family. Revisit if `claude` grows a models command,
or if someone needs a specific version pinned.

## 6. Sign-in is not re-probed while the Palette is open — **v1.0**

The Palette probes on the first `!c` of a summon and reuses the answer until it
is dismissed. Sign in through a CLI while the Palette is up and it will still say
signed out.

Deliberate: an interval here is three process spawns per tick, against a surface
whose whole promise is that it costs nothing. Settings has `Check again`, and
dismissing the Palette drops the cache. Revisit alongside TBC-0012, whose
terminal path needs a re-probe loop anyway.

## 7. A long answer has nowhere to go but a fixed-height box — **v1.0**

The conversation occupies the Palette at `VIEW_HEIGHT`, the same fixed height
`!v` uses, and scrolls inside it. That is right for a paragraph and cramped for a
page, and unlike the Entry list it cannot grow with its content: the window is
already at the height TBC-0006 chose as the ceiling for a launcher.

Not a bug, and not obviously fixable without deciding what a launcher is for.
Belongs with v1.0's polish pass and with whatever §3 concludes about
conversations that outlive a summon.

## 8. No Turn is measured — **v1.0**

`bun run bench` covers the four budgets in `IMPLEMENTATION_PLAN.md` §10, none of
which are about Agents. First-token latency on the inline path is the number
people will judge `!c` by, and nothing records it.

The plan says to measure before choosing a session model and the choice was made
on other grounds (crash-safety, and only one of three CLIs offering a persistent
input stream). That reasoning stands, but it should be checked against a number
before v1.0, with the revisit trigger the plan already names: 1.5 s to first
token on a resumed Turn.
