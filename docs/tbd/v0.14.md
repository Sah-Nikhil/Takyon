# v0.14 — to be done

The Windows image path is built. These gaps keep the broader clipboard-kinds
phase open.

## 1. macOS image capture and paste are not built — **v0.12 row 6, then v0.14**

The macOS clipboard watcher in v0.12 row 6 has not been built. `MacClipboard::write_image`
still refuses with "Image clips cannot be pasted on this platform yet." Once row 6
establishes the `NSPasteboard` watcher and paste-back path, the macOS half of
v0.14 must add `public.png` / `public.tiff` image capture, protected storage,
preview, and paste-back. A Mac build and a manual run close this gap; a Windows
test or macOS compile gate cannot.

## 2. `Files` kind is not built — **v0.14**

Windows `CF_HDROP` and macOS `public.file-url` capture and paste-back remain open.
The stored payload must contain paths only, never file contents. History must
show missing paths and refuse to paste an incomplete list. Implement and verify
both platform paths before checking the `Files` task.

## 3. Link classification is not built — **v0.14**

`Text` clips containing an `http(s)` URL still lack link classification, the
favicon, host subtitle, and Open action. Add these through the existing URL
parser and icon cache, then verify a copied URL stays a `Text` clip.

## 4. Copies offering text and image record text — **v0.14**

The Windows watcher prefers `CF_UNICODETEXT` because Excel and Word place a
bitmap beside selected cell text. A Firefox-style copy that offers both formats
therefore records text, even if the person intended to copy the image. Text that
is blank, over `MAX_CHARS` or unreadable falls through to the image. Verify
the affected browser flows, then decide whether an application-specific rule
can distinguish them without breaking Office copies.

## 5. All-zero alpha is treated as opaque — **v0.14**

Some 32bpp DIB producers leave every alpha byte at zero while supplying visible
RGB pixels. The decoder makes those images opaque. A genuinely transparent image
whose alpha is entirely zero and whose RGB channels carry data will lose that
transparency if it enters through DIB. Verify real clipboard producers and
adjust the heuristic if one exposes this case.

## 6. Manual verification has not run — **v0.14**

[`../verify/v0.14.md`](../verify/v0.14.md) is unrun. The Rust image round-trip
and disk tests cover Win32 clipboard and blob behavior, but cannot prove the
History UI, Paint or Word paste, password-manager exclusion, retention timing,
or restart reconciliation in a release build. Drive the script and record each
status before closing the Windows image half.
